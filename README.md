# 印记 · Android 安装包

记录旅票、地点、娱乐与随笔（日记 / 事迹）的小应用：列表、日历、地图三种视图，按月看自己的活动轨迹。

## 下载

到本仓库的 **[Releases](../../releases/latest)** 页面下载 `app-release.apk`。

- 支持系统：Android 8.0 及以上
- 安装包约 116 MB（包含地图与相册相关原生库）

## 安装

1. 手机浏览器打开上面的 Releases 页面，下载 `app-release.apk`；
2. 点击安装，系统提示「未知来源 / 风险」时选择**允许安装**（这是自行分发 APK 的正常提示）；
3. 若之前装过旧版本，直接覆盖安装即可；装不上就先卸载旧版再装。

> 这个安装包未上架任何应用商店，请只从本仓库的 Releases 下载。

## 首次使用

- **相册权限**：选图/加影像是直读系统相册（只记录引用，不复制文件），拒绝权限就用不了影像功能；
- **地图**（可选）：侧边栏「地图服务」里可以选 **天地图** 或 **高德**，填各自的 Key 才有底图与地名联想；
  - 天地图：在 lbs.tianditu.gov.cn 免费申请 **tk**；
  - 高德：底图不需要 Key，地名联想请在 lbs.amap.com 控制台申请 **「Web 服务」类型的 Key**（不是 JS API 那种）。而外配置了JS API
- **数据只存在本机**：所有记录、照片引用都在你自己的手机里，应用不联网上传任何内容；
  侧边栏提供「导出备份 / 导入备份」，换手机时用它迁移即可。

## 功能一览

- **列表 / 日历 / 地图** 三段视图：日历里有活动的日期会打彩色圆点，点日期看当天，可上滑把日历折叠成"本周"一行；
- **四类记录**：旅票（机票/火车票/汽车票/轮船）、地点、娱乐（电影/剧集/动漫/游戏/书籍）、随笔（日记/事迹）；
- 旅票可以填出发地/目的地，地图上会连成出行轨迹弧线；点标点看备注，连点两次飞到该点；
- 随笔支持心情 emoji（含自定义）与照片，日记另可记天气；
- 全程离线可用（地图瓦片除外），无账号、无广告、无埋点。
